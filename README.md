# Allsail

Premium marketing site for Allsail — yacht charter, sailing club and training from the Ferry Wharf at Church Point, Pittwater NSW.

## Stack

React 19, TanStack Start, Tailwind v4.

## Local

```bash
npm install
npm run dev
```

Opens on port 8080.
